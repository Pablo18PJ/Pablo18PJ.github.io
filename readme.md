# Pablo Jurado Leal — Portfolio

Portfolio personal, construido con [Astro](https://astro.build) y Tailwind CSS. Sitio estático, rápido y desplegado en GitHub Pages.

🔗 **Live:** [pablo18pj.github.io](https://pablo18pj.github.io)

## Stack

- **Framework:** [Astro](https://astro.build) — HTML estático, mínimo JS
- **Estilos:** Tailwind CSS
- **Contenido:** Astro Content Collections (proyectos en Markdown/JSON)
- **Gestor de paquetes:** pnpm
- **Despliegue:** GitHub Pages vía GitHub Actions

## Desarrollo local

Requisitos: Node.js 22+, pnpm.

```bash
pnpm install
pnpm dev
```

```bash
pnpm build
pnpm preview
```
